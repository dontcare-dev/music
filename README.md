# Silver Music

Cross-platform music player for Android and Windows.

## Current features

- Automatic local music discovery on Android and Windows.
- Android MediaStore library access with runtime permission request.
- Windows Music and Downloads folder scan.
- Manual audio-file import fallback.
- Persistent library, liked tracks, local search, and queue playback.
- SVG-based controls and responsive desktop/mobile layouts.
- Bundled provider modules are installed automatically on first launch.

## Build

GitHub Actions builds Android release APKs and Windows release bundles on pushes to `main`.

Community plugin execution, remote streaming providers, background media sessions, and installer packaging are not yet implemented.
